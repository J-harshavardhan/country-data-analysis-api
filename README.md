# 🌍 Country Data Analysis using REST API

## 📌 Project Overview

This project demonstrates how to fetch real-time country data from a public REST API, process it using Python, and perform basic data analysis and visualization.

It simulates a real-world data analyst task where data is retrieved programmatically instead of using local files.

---

## 🚀 Features

* 📡 Fetch live data from REST API
* 🧹 Clean and structure JSON data
* 📊 Convert data into Pandas DataFrame
* 📈 Visualize population distribution by region
* 🔍 Perform analytical insights

---

## 🔗 API Used

* **REST Countries API**
  https://restcountries.com/v3.1/all

No API key required.

---

## 🛠️ Technologies Used

* Python 🐍
* Requests (API handling)
* Pandas (data processing)
* Matplotlib (visualization)
